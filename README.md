# Ajib Paudel — personal portfolio

A responsive, static portfolio based on the October 26, 2026 CV. No build process or JavaScript dependencies are required.

## Edit

- `index.html`: biography, projects, experience, education, and links.
- `styles.css`: colors, typography, and responsive layout.
- `Ajib_Paudel_CV.pdf`: downloadable original CV. Replace this file to update the download.

Google Fonts provides DM Sans and Libre Caslon Display; system fonts are used if unavailable. The site does not include analytics or a contact form. Email uses a mailto link.

## Preview

Run `python3 -m http.server 8765` in this directory and open http://localhost:8765.

## Publish to GitHub Pages

Use the `paudelajib/paudelajib.github.io` repository for https://paudelajib.github.io/. If that repository already exists, review its contents before replacing any files.

Upload the files in this directory, including the PDF and `.nojekyll`, to the repository root. In Settings → Pages, choose Deploy from a branch, select the default branch and `/ (root)`, and save.

The stock scanner remains a separate repository and is linked from this website. The downloadable PDF is the original supplied CV, including its contact information.

Project metrics and research claims reflect the supplied CV; the website does not independently re-evaluate the underlying models or live demo.
